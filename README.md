# HTML Events – Practical Examples

A beginner-friendly web development project demonstrating different HTML events using practical examples. This repository helps learners understand how web pages respond to user interactions such as dragging elements, keyboard actions, mouse movements, and text input.

## 📌 Project Overview

HTML events are actions or occurrences detected by the browser, which can be handled using JavaScript. This project contains individual HTML files demonstrating common events used in interactive web applications.

## 📂 Project Structure

```text
WPT-HTML-EVENT/
│
├── Drag-Event.html
├── Keyboard-Event.html
├── OnMouseOver-Event.html
├── Text-Box-Event.html
├── key-Press-Event.html
│
└── README.md
```

## ✨ Examples Included

| File Name | Description |
|---|---|
| `Drag-Event.html` | Demonstrates drag-related interactions. |
| `Keyboard-Event.html` | Demonstrates keyboard event handling. |
| `OnMouseOver-Event.html` | Demonstrates actions triggered when the mouse moves over an element. |
| `Text-Box-Event.html` | Demonstrates events associated with text box input. |
| `key-Press-Event.html` | Demonstrates key-press-related keyboard interactions. |

## 🎯 Project Objectives

- Understand the fundamentals of HTML events.
- Learn how JavaScript handles user interactions.
- Explore mouse, keyboard, drag, and text input events.
- Practice creating interactive web pages.
- Build a foundation for more advanced frontend development.

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages.
- **JavaScript** – Event handling and interactive behavior.
- **CSS** – Styling, if included in individual examples.

## 🚀 Getting Started

No installation or additional dependencies are required.

1. Clone the repository:

   ```bash
   git clone https://github.com/Prathamesh-Jadhav04/WPT-HTML-EVENT.git
   ```

2. Open the project folder:

   ```bash
   cd WPT-HTML-EVENT
   ```

3. Open any `.html` file in your preferred web browser.

4. Interact with the page to explore the demonstrated event behavior.

Alternatively, download the repository as a ZIP file from GitHub and extract it locally.

## 📚 Learning Outcomes

After exploring this project, learners should have a better understanding of browser events, event handling, and the role of JavaScript in creating interactive web pages.
